# プラグイン導入コマンドの明確化

## 要点

README.md 内の該当箇所を直接テキスト置換する方式を採る。動的にリポジトリ情報からコマンドを生成する仕組み(スクリプト化・CI での自動置換など)は検討したが、変更対象が1行のみであり、そのための仕組みを持つコストに見合わないため採らない。

## 実装アプローチ

`README.md` の「使い方」手順1にあるコードブロック

```
claude plugin marketplace add <owner>/claude-plugins
```

を

```
claude plugin marketplace add JHashimoto0518/claude-plugins
```

に書き換える。

## 変更するコンポーネント

- `README.md`(該当コードブロック1箇所のみ)

## データ構造の変更

なし

## 影響範囲の分析

- ドキュメントのみの変更であり、スキル・フック・`.claude/settings.json` などの動作には影響しない
- 後方互換性への影響なし(本番未リリースのため、そもそも後方互換性への配慮は不要)
- `docs/` 配下・他の `README*.md`(英語版は既に廃止済み)への影響なし
