# git pushをClaudeが実行可能にする

> **[中止]** 2026-08-13、要件検討の途中でこのステアリングを中止した。別のステアリングとして仕切り直す。

## 目的

git pushをClaudeが実行可能にすることで、リポジトリへの変更を自動的に反映させることができるようになる。

現状では、Claudeはgit pushを実行する権限を持っていないため、リポジトリへの変更を反映させることができない。

## 注意事項

ポリシーはリポジトリによって異なる場合がある。

以下に対応できればうれしいが、可能か？

- コミットの際に承認なしでpushまで実施
- コミットの後にpushは承認を待ってから実施
- pushは禁止（現状と同じ）
