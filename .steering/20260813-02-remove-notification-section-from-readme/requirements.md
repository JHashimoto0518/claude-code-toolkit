# READMEから通知セクションを削除する

## 要点

`README.md` の「通知」セクション(Remote Control 機能の説明)を削除する。このリポジトリは Remote Control を実装・設定するコード(フック・スキル・設定ファイルなど)を一切持たず、Claude Code 本体の標準機能をそのまま解説しているだけであり、このリポジトリの README に置く情報ではない。

今の方式で捨てるのは「このリポジトリが配布する設定と直接関係のない、Claude Code 本体の一般的な使い方ガイドも README に含める」という方針。README はこのリポジトリが提供するもの(スキル・フック・権限設定)の説明に絞る。

## 背景

`README.md` には「通知」セクションがあり、Claude Code の Remote Control 機能(公式アプリへのプッシュ通知)のペアリング手順・設定手順を説明している。`grep` で確認したところ、このリポジトリ内で Remote Control に関連するコード・設定・フックは存在せず(該当するのは `README.md` のみ)、記載内容は Claude Code 公式ドキュメントの要約にとどまっている。

このリポジトリの README は「含まれるもの」節にあるとおり、スキル・フックなど本リポジトリが配布するコンポーネントの説明を目的としており、本リポジトリが関与しない Claude Code 標準機能の解説を含めるのは目的から外れる。
