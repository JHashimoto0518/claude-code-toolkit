# 開発中ステータスの明示

## 要点

**`README.md` と `README.en.md` の両方に、このリポジトリが開発中であり破壊的変更が発生し得る旨を明示する記述を追加する。** 今回捨てるのは「開発中・後方互換性非保証という方針が `claude.md` の内部ポリシーとしてのみ存在し、リポジトリの入り口である README には一切現れていない」状態である。

## 背景

`plugins/core/.claude-plugin/plugin.json` の `version` は `0.1.0` であり、`claude.md` の「バージョニングと後方互換性ポリシー」の定義に従えばベータ版に該当する。ベータ版では後方互換性を担保せず、破壊的変更を自由に行ってよいと定められている。

一方で `README.md` / `README.en.md` は、このリポジトリの構成・使い方・権限方針・ステアリング運用は説明しているが、開発段階や後方互換性についての言及はない([`../20260810-02-update-readme/`](../20260810-02-update-readme/) で内容を実態に合わせて更新した際も、この観点は対象に含まれていなかった)。このリポジトリをマーケットプレイスとして登録し `core` プラグインを導入する利用側リポジトリの担当者にとって、README がこのリポジトリの説明を読む最初の(そして通常唯一の)場所であり、`claude.md` の内部ポリシーまでは通常読まない。そのため、破壊的変更が起こり得ることが README からは伝わらない。

## 変更・追加する機能の説明

### 1. README.md への追記

このリポジトリが開発中であり、後方互換性を保証しない(スキル・フックの仕様やインターフェースが予告なく変わり得る)旨を明示する記述を追加する。具体的な配置(冒頭・独立セクションなど)と文言は design.md で決める。

### 2. README.en.md への対応する追記

日本語版と対になる内容を英語で追加する。

## 受け入れ条件

- [ ] `README.md` に、開発中であり破壊的変更が発生し得る旨を明示する記述がある
- [ ] `README.en.md` に、`README.md` と対応する内容が英語で記述されている
- [ ] 記載内容が `claude.md` の「バージョニングと後方互換性ポリシー」(ベータ版は後方互換性を担保しない)と矛盾しない

## 制約事項

- 変更範囲は `README.md` / `README.en.md` に限る。`claude.md` 自体の変更は行わない(既にポリシーが定義済みのため)
- `plugins/core/.claude-plugin/plugin.json` の `version` 値そのものの変更は対象外(バージョン番号の運用は本ステアリングのスコープ外)
