# READMEの更新

## 要点

`README.md` は現在「Shared Claude Code plugins (skills, hooks, etc.) for use across multiple repositories」という 1 行説明のみで、リポジトリ作成時のデフォルトから更新されていない。**日本語版 `README.md` を実態(スキル・フック・ステアリング運用・権限方針などの構成)を反映した内容に更新し、新たに英語版 `README.en.md` を作成する。両ファイルは相互にリンクし、読者が言語を切り替えられるようにする。**

今回捨てるのは「READMEが空の説明で放置されている」状態であり、英語版が存在しないことも合わせて解消する。日本語版・英語版のどちらを正本とするかは決めず、対等な 2 言語として維持する(design.md で言語間の同期方針を決める)。

## 背景

このリポジトリ (`claude-plugins`) は、複数のリポジトリで共有する Claude Code の設定(スキル・フック・権限設定など)を管理する。直前のステアリング([`[REMOVED]`]([REMOVED]))で、`[REDACTED]` からコピーした設定一式(`claude.md` / `.claude/` / `.devcontainer/`)からプロダクト固有の情報を除去し、共有設定として成立する状態に汎用化した。

その際 `README.md` は「複数リポジトリで共有する Claude Code のプラグイン」という説明であり変更後の内容と矛盾しないと判断し、更新対象から外した([`[REMOVED]design.md`]([REMOVED]design.md) の「永続的ドキュメントへの影響」参照)。矛盾はしないが、リポジトリ作成時のデフォルトのまま 1 行しかなく、このリポジトリが何を提供し、どう使うかが README からは読み取れない。

## 変更・追加する機能の説明

### 1. README.md(日本語版)の更新

現状の 1 行説明を、リポジトリの実態に基づいた内容へ更新する。対象は現在のリポジトリ構成(`.claude/skills/commit`・`.claude/skills/steering-new` の 2 スキル、`.claude/hooks/` の 3 フック、`.claude/settings.json` の権限方針、`.devcontainer/`)であり、具体的な章立てと記載内容は design.md で決める。

### 2. README.en.md(英語版)の新規作成

日本語版と対になる内容を英語で作成する。翻訳の単位・同期の取り方(全文翻訳か要約か、更新時に両ファイルをどう保つか)は design.md で決める。

### 3. 言語切り替えリンクの追加

`README.md` と `README.en.md` の双方に、もう一方の言語版へのリンクを設置する。配置場所(冒頭・末尾など)は design.md で決める。

## 受け入れ条件

- [ ] `README.md` が、リポジトリ作成時のデフォルトの 1 行説明から、実際のスキル・フック・権限方針・ステアリング運用を反映した内容に更新されている
- [ ] `README.en.md` が新規に作成され、`README.md` と対応する内容を英語で持つ
- [ ] `README.md` から `README.en.md` へ、`README.en.md` から `README.md` へ、それぞれ言語切り替え用のリンクがある
- [ ] 記載内容が、直前のステアリングで汎用化した設定(プロダクト固有情報を含まない状態)と矛盾しない

## 制約事項

- 今回の変更範囲は `README.md` / `README.en.md` に限る。`claude.md` やスキル本体(`.claude/skills/**/SKILL.md`)の内容変更は行わない(必要な差異が見つかった場合は別途報告する)
- このリポジトリに `docs/` は存在しないため、`docs/` 配下の更新は対象外
- 公開リポジトリであるため、プロダクト固有の情報(特定の利用リポジトリ名・パスなど)を新たに持ち込まない
