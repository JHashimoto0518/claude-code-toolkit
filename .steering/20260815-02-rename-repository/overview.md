# リポジトリ名の変更

## 目的

> 複数のリポジトリで共有する Claude Code の設定(スキル・フック・権限設定など)を管理するリポジトリです。

READMEに記載があるとおり、このリポジトリはプラグインだけでなく、プログジェクトメモリ、devcontainer、permission など Claude Codeを利用する上での共有リソースを管理するリポジトリである。

実態と名称が乖離しているため、リポジトリ名を変更した方がよいのではないか。

まず、あなたの見解を聞きたい。変更に同意する場合は、名称案を出してほしい。

## 注意事項

このプラグインは未配布であるため、名称変更による配布先リポジトリへの影響は考慮不要である。
