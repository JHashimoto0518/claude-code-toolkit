# READMEの多言語化廃止

## 要点

**`README.en.md` を削除し、`README.md` から英語版への言語切り替えリンクと「両言語を更新してください」という同期の注記を取り除く。** 今回捨てるのは「`README.md`(日本語)と `README.en.md`(英語)を対になる2言語として維持する」という [`../20260810-02-update-readme/`](../20260810-02-update-readme/) で導入した運用であり、`README.md` を唯一の README として一本化する。

## 背景

[`../20260810-02-update-readme/`](../20260810-02-update-readme/) で、それまで1行説明しかなかった `README.md` を実態に即した内容に更新し、対になる `README.en.md` を新規作成した。当時の design.md は「対等な2言語として維持し、更新時は両ファイルを同期する」方針を採ったが、同期を強制する仕組み(CI・フック)は設けず、末尾の注記による運用ルールのみだった。

このリポジトリで管理するリソース(スキル・フック・`claude.md`・ステアリング運用など)は日本語のコメント・ドキュメントで統一されており、英語で参照可能なのは README のみという状態になっている。README だけを英語で読めても、そこから先(`claude.md` やスキル本体)は日本語のため、英語版 README を維持する意味が薄い。

## 変更・追加する機能の説明

### 1. README.en.md の削除

ファイルそのものを削除する。

### 2. README.md からの多言語関連記述の除去

- H1 直下の言語切り替えリンク行(`日本語 | [English](README.en.md)`)を削除する
- 末尾の同期の注記(「このファイルを更新する際は、対になる [README.en.md](README.en.md) も合わせて更新してください。」)を削除する
- 上記以外の本文(概要・含まれるもの・使い方・権限方針の要点・ステアリング運用・開発中ステータスの注意書き)は変更しない

## 受け入れ条件

- [ ] `README.en.md` が削除されている
- [ ] `README.md` に言語切り替えリンクが存在しない
- [ ] `README.md` に「対になる README.en.md」への言及が存在しない
- [ ] `README.md` の残りの内容(多言語関連以外)が変更されていない

## 制約事項

- 変更範囲は `README.md` の多言語関連の記述と `README.en.md` の削除に限る。他のセクションの内容・構成の見直しは行わない
- `claude.md` やスキル本体に多言語化の記述はないため、変更対象に含めない
