# READMEの多言語化廃止

## 要点

**`README.en.md` を削除し、`README.md` から言語切り替えリンク(H1直下)と同期の注記(末尾の `---` 区切りブロック)を取り除く。** 変更対象はこの2箇所のみで、他の構成・見出し・本文には手を入れない。

| 論点 | 方式 | 決め手 |
|---|---|---|
| `README.en.md` の扱い | 削除する | 「廃止」という要求どおり、参照可能な英語版を残さない。`grep` で確認した限り `README.md` 以外から参照されていないため、削除しても壊れるリンクは生じない |
| `README.md` 末尾の同期注記 | 削除する(`---` 区切り含めて丸ごと) | 注記は「対になる README.en.md も更新してください」という、対になるファイルの存在を前提にした内容。対象ファイルがなくなるため丸ごと不要になる。`---` は注記を本文と区切るためだけの罫線であり、注記削除後に残す理由がない |

### 採らなかった選択肢

- **`README.en.md` を残しつつ「メンテナンスされていません」という注記を追加する** — 要求は多言語化そのものの廃止であり、古い英語版を残すと内容が `README.md` と乖離した際に誤読を招く。ファイルごと削除する方が明確
- **言語切り替えリンクだけ削除し、`README.en.md` は残す** — 到達手段のない孤立ファイルが残り、`README.en.md` を直接開いた読者には廃止の意図が伝わらない。ファイル自体を消すほうが一貫している

## 実装アプローチ

### 1. README.en.md の削除

`git rm README.en.md` でファイルを削除する。

### 2. README.md の編集

H1 直下の言語切り替えリンク行を削除する。

```diff
 # claude-plugins

-日本語 | [English](README.en.md)
-
 複数のリポジトリで共有する Claude Code の設定(スキル・フック・権限設定など)を管理するリポジトリです。
```

末尾の `---` 区切りと同期注記のブロックを削除する。

```diff
 特定の開発作業の要求・設計・タスクは `.steering/[YYYYMMDD]-[NN]-[開発タイトル]/` に記録します。作成する場合は `/core:steering-new [開発タイトル]` スキルを使います。詳細は `claude.md` と `plugins/core/skills/steering-new/SKILL.md` を参照してください。
-
----
-
-このファイルを更新する際は、対になる [README.en.md](README.en.md) も合わせて更新してください。
```

## 変更するコンポーネント

| ファイル | 変更内容 |
|---|---|
| `README.en.md` | 削除 |
| `README.md` | 言語切り替えリンク行(H1直下)と末尾の同期注記ブロック(`---`含む)を削除。他の内容は変更しない |

## データ構造の変更

なし。Markdown ファイルの削除・部分編集のみ。

## 影響範囲の分析

### 動作への影響

- **PostToolUse フック(`posttooluse-doc-check.sh`)**: 対象を `docs/*.md README*.md` のグロブで拾う仕組みで、特定ファイル名をハードコードしていない。`README.en.md` が存在しなくなってもグロブは単に対象が1つ減るだけで、フック自体の変更は不要
- **他のフック・スキル・設定**: `grep` で確認した限り、`README.en.md` を参照しているのは `README.md` 自身のみ。他のコード・設定・スキル本体からの参照はない

### 後方互換性

このリポジトリは `claude.md` の定義するベータ版であり後方互換性を担保しない方針。加えて README はAPIや設定スキーマではなく外部から機械的に参照されるものではないため、ファイル削除・記述変更による利用者への破壊的影響はない。移行手順は不要。

### 永続的ドキュメント(`docs/`)への影響

このリポジトリに `docs/` は存在しないため、更新対象なし。

### 今回の範囲外

- `README.md` の多言語関連以外の構成・文言の見直し(要求のスコープ外)
- 過去のステアリングディレクトリ(`.steering/20260810-02-update-readme/` など)内の記述の書き換え(過去の意思決定の記録であり、現在の方針変更に合わせて改変しない)
